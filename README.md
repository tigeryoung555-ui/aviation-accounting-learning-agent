# 民用航空运输企业会计学习智能体

面向本科民航会计课程的智能学习系统，支持学生端学习练习与教师端教学管理。

> **题库说明**：本版已将旧版《民用航空运输企业会计》单课程题库（1014 题，以物流企业会计 10 章为骨架、民航特色内容作为特色注入）并入原 MVP（206 题，民航专题 10 章），合并后共 **1219 题 / 19 章**。其中民航特色题 687 道、物流通用题 532 道。

## 功能特性

### 学生端（6大模块）
- **学习仪表盘**：题库总量、学习进度、正确率、错题数一览
- **知识学习**：19章核心知识（民航专题 10 章 + 物流骨架 10 章，其中"财务报告"章合并），按章节系统学习
- **智能练习**：1219题全量题库，8种题型，按章节/题型筛选
  - 客观题（单选/多选/判断）自动评阅
  - 主观题（分录/计算/简答/名词解释/案例）关键词匹配初评
- **AI答疑**：基于162条知识库的RAG检索增强答疑（民航28条 + 物流134条知识点）
- **成绩分析**：各章正确率、知识点掌握度、薄弱点优先
- **错题本**：自动归集错题，针对性复习

### 教师端（4大模块）
- **教学概览**：题库统计、班级平均分、成绩分布直方图
- **题库管理**：按章节/题型筛选浏览，表格展示全部题目
- **自动组卷**：设置题型题量、难度分布、章节范围，一键随机抽题，支持导出TXT
- **班级成绩**：45人模拟数据，成绩分布、排名表、各章正确率热力图

## 题库统计
- **总量**：1219题（原 MVP 206 + 旧版并入 1013，去重 1）
- **覆盖**：19章（民航专题 10 章 + 物流骨架 10 章，其中"财务报告"章合并）
- **题型**：单选384 + 多选201 + 判断295 + 名词解释70 + 简答108 + 分录41 + 计算分析85 + 案例35
- **属性**：民航特色 687 / 物流通用 532

## 课程体系（两部分）
**民航专题 10 章**：概论 → 流动资产 → 飞机发动机 → 飞机租赁 → 运输成本 → 票证收入 → 负债权益 → 财务报告 → 报表分析 → 外币合并

**物流骨架 10 章**（并入）：物流企业会计概论 → 经营准备的管理与核算 → 存货的管理与核算 → 长期资产的管理与核算 → 成本和费用的管理与核算 → 流动负债的管理与核算 → 收益及分配的管理与核算 → 财务报告（与民航章合并）→ 外币业务的管理与核算 → 新技术在物流企业会计中的应用

## 技术栈
- 纯前端单文件HTML应用
- 原生HTML/CSS/JavaScript，无框架依赖
- localStorage本地数据持久化
- 响应式设计，支持移动端

## 使用方法
直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

## 文件说明
- `index.html`：主应用（单文件自包含，1219题+AI答疑+教师端）
- `gen_mvp_v2.py`：应用生成脚本（读取 questions.json 生成 index.html，并合并补充章节/知识库）
- `questions.json`：合并后题库数据（1219题）
- `chapter_content_extra.json`：旧版物流 10 章补充内容（并入 CHAPTER_CONTENT）
- `kb_extra.json`：旧版 134 条知识点知识库（并入 KNOWLEDGE_BASE，增强 AI 答疑）
- `merge_old_bank.js`：合并脚本（旧版 1014 题 → MVP 格式，生成本仓库的 questions.json 与补充文件）
- `questions_mvp206_backup.json` / `index_mvp206_backup.html`：合并前原始 MVP 备份
