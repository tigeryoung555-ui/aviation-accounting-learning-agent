# 民用航空运输企业会计学习智能体

面向本科民航会计课程的智能学习系统，支持学生端学习练习与教师端教学管理。

## 功能特性

### 学生端（6大模块）
- **学习仪表盘**：题库总量、学习进度、正确率、错题数一览
- **知识学习**：10章核心知识，按章节系统学习
- **智能练习**：206题全量题库，8种题型，按章节/题型筛选
  - 客观题（单选/多选/判断）自动评阅
  - 主观题（分录/计算/简答/名词解释/案例）关键词匹配初评
- **AI答疑**：基于28条民航会计知识库的RAG检索增强答疑
- **成绩分析**：各章正确率、知识点掌握度、薄弱点优先
- **错题本**：自动归集错题，针对性复习

### 教师端（4大模块）
- **教学概览**：题库统计、班级平均分、成绩分布直方图
- **题库管理**：按章节/题型筛选浏览，表格展示全部题目
- **自动组卷**：设置题型题量、难度分布、章节范围，一键随机抽题，支持导出TXT
- **班级成绩**：45人模拟数据，成绩分布、排名表、各章正确率热力图

## 题库统计
- **总量**：206题
- **覆盖**：10章39个知识点
- **题型**：单选65 + 多选36 + 判断35 + 名词解释21 + 简答17 + 分录13 + 计算分析13 + 案例6
- **难度**：易47 / 中130 / 难29

## 课程体系（10章52学时）
1. 概论（4学时）
2. 流动资产（6学时）
3. 飞机发动机核算（8学时）
4. 飞机租赁（6学时）
5. 运输成本（8学时）
6. 票证收入（6学时）
7. 负债与所有者权益（4学时）
8. 财务报告（4学时）
9. 财务报表分析（4学时）
10. 外币业务与合并报表（2学时）

## 技术栈
- 纯前端单文件HTML应用
- 原生HTML/CSS/JavaScript，无框架依赖
- localStorage本地数据持久化
- 响应式设计，支持移动端

## 使用方法
直接在浏览器中打开 `index.html` 即可使用，无需安装任何依赖。

## 文件说明
- `index.html`：主应用（单文件自包含，206题+AI答疑+教师端）
- `gen_mvp_v2.py`：应用生成脚本
- `questions.json`：题库数据（206题）
